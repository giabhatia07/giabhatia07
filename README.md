### Featured Projects

**Does Private Consumption in India Follow a Random Walk?**  
An empirical study of Indian private consumption using R, stationarity testing and ARIMA forecasting. The project compares the predictive performance of autoregressive models against a random-walk benchmark.

**Coffee Shop Sales Analysis**  
An interactive Excel dashboard exploring sales trends, product performance, store-level revenue and customer purchasing patterns using PivotTables, slicers and lookup formulas.
